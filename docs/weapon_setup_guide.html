0 Common Setup — Every Weapon Follows This

1

Create the Wieldable Scene

In Godot editor, create a new scene with this exact node structure. Save it as res://Sneces/Weapons/YourGun.tscn.

YourGun (Node3D) ← attach cogito_weapon.gd ├─ AnimationPlayer (AnimationPlayer) ← required by CogitoWieldable ├─ AudioStreamPlayer3D (AudioStreamPlayer3D) ← required by CogitoWieldable ├─ WeaponMesh (Node3D) ← assign to "wieldable_mesh" │ └─ MeshInstance3D (MeshInstance3D / imported model) └─ Bullet_Point (Marker3D) ← MUST have unique name (% prefix)
⚠️

The Bullet_Point node must have Unique Name in Owner checked (right-click → Access as Unique Name). The script uses %Bullet_Point to find it.

2

Attach the Script and Configure Exports

Select the root node, attach res://Scripts/Weapons/cogito_weapon.gd. Then set in the Inspector:

ExportValueDescription
wieldable_meshWeaponMesh nodeDrag the WeaponMesh node here — auto-hidden on unequip
weapon_dataYourGun_Resource.tresThe Weapon_Resource or subclass for this gun
anim_equip"equip"AnimationPlayer animation name for equip
anim_unequip"unequip"AnimationPlayer animation name for holster
anim_action_primary"shoot"AnimationPlayer animation name for fire
anim_reload"reload"AnimationPlayer animation name for reload
sound_shootfire.oggAudio for each shot
sound_reloadreload.oggAudio for reload
default_positionVector3(0.2, -0.2, -0.3)Hip-fire local position — used for ADS tween return
ads_fov65.0Camera FOV when aiming down sights (degrees)
3

Create a WieldableItemPD Resource

In FileSystem, right-click a folder → Create New Resource → WieldableItemPD. Configure:

PropertyExample ValueNotes
name"Pistol"Display name in inventory
wieldable_scenePistol.tscnThe scene you created in Step 1
charge_max15Magazine size
charge_current15Starting ammo in magazine
wieldable_damage25.0Damage per bullet / per pellet
wieldable_range50.0Hitscan ray length (metres)
ammo_item_name"9mm Ammo"Must match the name of an AmmoItemPD
no_reloadfalseKeep false for all gun types
ℹ️

Ammo items are separate AmmoItemPD resources. Create one (e.g. 9mm_Ammo.tres), set its name to match ammo_item_name above, and set reload_amount = 1.

4

Add to Player Inventory

Open addons/cogito/InventoryPD/Inventories/PlayerInventory_FIXED.tres. Add an inventory slot with your WieldableItemPD. Then assign it to a quickslot (keys 1–4 in-game).

ℹ️

Press F (interact) on a weapon pickup, or open inventory (Tab) and use the item to equip it. Right-click → Assign to quickslot for fast access.

5

Input Actions (already mapped)

ActionDefault KeyEffect
action_primaryLeft MouseFire / hold for auto
action_secondaryRight MouseHold to aim down sights
reloadRReload from inventory ammo
quickslot_1–41, 2, 3, 4Equip weapon in that slot
⚠️

Check Project → Project Settings → Input Map and ensure action_primary = Left Mouse Button and action_secondary = Right Mouse Button if they appear misconfigured.

1 Pistol

🔫

Pistol

Resource class: Pistol_Resource
SEMI-AUTO Hitscan or Projectile
1

Create the Weapon_Resource

Right-click → New Resource → Pistol_Resource. Configure it:

PropertyExampleNotes
weaponName"Pistol"Identifier string
triggerResetTime0.15Min seconds between shots (prevents holding fire)
recoilVertical0.15Upward kick per shot (radians)
recoilHorizontal0.08Side kick random range
TypeHitscan (1)Or Projectile (2) if you have a bullet scene
bulletProjectileToLoad—Only needed if Type = Projectile
weaponVelocity—Only needed if Type = Projectile
2

Follow Common Setup

Complete all 5 steps in Common Setup. The pistol uses only the base animations — no extra animation exports needed.

ℹ️

Fire rate is controlled by triggerResetTime on the resource. The shoot animation can be any length — the cooldown timer prevents spamming regardless.

3

3 Shotgun

💥

Shotgun

Resource class: Shotgun_Resource
PUMP-ACTION or SEMI Multi-Pellet Hitscan
1

Create Shotgun_Resource

PropertyExampleNotes
pelletCount8Hitscan rays fired per shot
spreadAngle4.0Hip-fire spread cone half-angle (degrees)
adsSpreadAngle2.0ADS spread cone half-angle (tighter)
isPumptrueIf true, requires pump animation between shots
pumpAnimation"pump"Animation name for the pump action — must exist in AnimationPlayer
2

Animations required in AnimationPlayer

"equip" ← play on draw "unequip" ← play on holster "shoot" ← single fire blast "pump" ← pump cycle after each shot (if isPump = true) "reload" ← plays once; PIC handles ammo transfer
⚠️

The pump sequence is: shoot animation → [auto-triggers] → pump animation → ready to fire again. The script blocks firing until pump animation finishes.

3

WieldableItemPD values for Shotgun

name             = "Shotgun"
charge_max       = 8    # tube capacity
charge_current   = 8
wieldable_damage = 12.0  # damage per individual pellet
wieldable_range  = 30.0
ammo_item_name   = "Shotgun Shells"
ℹ️

wieldable_damage applies to each pellet. With 8 pellets at 12 damage, a point-blank hit deals up to 96 total damage.

4 Bolt-Action Rifle

🎯

Bolt-Action Rifle

Resource class: BoltAction_Resource
BOLT-ACTION Hitscan
1

Create BoltAction_Resource

PropertyExampleNotes
boltCycleAnimation"bolt_cycle"Plays automatically after each shot. Must exist in AnimationPlayer.
boltCycleDuration0.8Reference duration — actual fire delay is animation length
recoilVertical0.4Strong upward kick for a powerful rifle
recoilHorizontal0.1Minimal side drift
TypeHitscan (1)Standard — high-power bullets
2

Animation sequence

The bolt-action fire loop works as follows:

"shoot" ← fires the shot + plays this animation ↓ (animation_finished) "bolt_cycle" ← automatically triggered after shoot ↓ (animation_finished) ready to fire again
ℹ️

The gun is locked between shot and bolt-cycle completing. Make bolt_cycle as long as you want the recycle delay to feel.

7 LMG (Light Machine Gun)

🌡️

LMG

Resource class: LMG_Resource
FULL AUTO HEAT SYSTEM Hitscan
1

Create LMG_Resource

PropertyExampleNotes
fireRate600.0Rounds per minute
heatPerShot0.05Heat added per shot (0.0–1.0). At 0.05, overheats after 20 shots.
cooldownRate0.1Heat lost per second when trigger is released (passive)
ventRate0.4Heat lost per second during active vent (hold R while hot)
ventAnimation"vent_heat"Animation name for vent action — must exist in AnimationPlayer
recoilVertical0.08Per-shot kick (lower than AR for sustained fire)
2

Heat system behaviour

Fire → heat rises by heatPerShot each shot Heat ≥ 1.0 → gun jams, firing stops automatically Release trigger → heat drops at cooldownRate/s (passive) Press R (while heat > 0) → plays vent_heat animation, heat drops at ventRate/s Heat = 0 → vent finishes, ready to fire again
ℹ️

Pressing R when the LMG is hot triggers the vent instead of a normal reload. Normal reload only runs when heat is 0 and the magazine is not full.

3

Required animations

"equip" "unequip" "shoot" "reload" "vent_heat" ← must match ventAnimation on the resource
4

WieldableItemPD values

name             = "LMG"
charge_max       = 100
charge_current   = 100
wieldable_damage = 14.0
wieldable_range  = 80.0
ammo_item_name   = "7.62 Ammo"

8 Grenade Launcher

💣

Grenade Launcher

Resource class: GrenadeLauncher_Resource
SEMI-AUTO PROJECTILE
1

Create GrenadeLauncher_Resource

PropertyExampleNotes
grenadeScenegrenade.tscnPackedScene for the grenade projectile. Must be a physics body (RigidBody3D).
launchAngle25.0Degrees above camera forward direction
launchVelocity20.0Initial speed in m/s
fuseDuration3.0Seconds until detonation (0 = impact only)
blastRadius5.0Explosion radius in metres
2

Grenade scene requirements

The grenade scene must be a RigidBody3D with these properties/methods:

# Your grenade script needs these members:
var damage_amount : int     # set by launcher on spawn
var fuse_duration : float   # set by launcher on spawn
var blast_radius  : float   # set by launcher on spawn
# RigidBody3D has set_linear_velocity() built-in
# Explosion should emit damage_received on nearby bodies
ℹ️

The grenade launcher ignores weapon_data.Type — it always spawns the projectile scene regardless of Hitscan/Projectile flag. The wieldable_damage on WieldableItemPD is passed to the grenade's damage_amount.

3

WieldableItemPD values

name             = "Grenade Launcher"
charge_max       = 6
charge_current   = 6
wieldable_damage = 100.0  # passed to grenade.damage_amount
wieldable_range  = 1.0    # not used for grenade, set any value
ammo_item_name   = "40mm Grenades"
