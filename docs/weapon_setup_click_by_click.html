Godot 4.6.1 + Cogito 1.1.5

Hướng dẫn setup weapon mới theo kiểu AK-47

Tài liệu này bám đúng cấu trúc project hiện tại của bạn. Mục tiêu là để bạn tạo một weapon mới từ model .glb, gán Weapon_Resource, gán WieldableItemPD, gán pickup, tạo animation đúng tên, rồi test ngay trong Town.tscn.

Main scene hiện tại: Town.tscn Tool đang dùng: Scripts/Tool/weapon_setup_tool.gd Reference chính: AK47

Mục lục

1. Bạn sẽ tạo những gì 2. Mở AK47 để đối chiếu 3. Dùng weapon setup tool 4. Tạo Weapon_Resource 5. Tạo WieldableItemPD 6. Cấu hình weapon scene 7. Cấu hình pickup scene 8. Tạo animation đúng tên 9. Thả vào Town để test 10. Lỗi hay gặp

Path cần nhớ

  • Project này đang dùng res://Sneces/Weapom/, không phải Scenes/Weapon.
  • AK47 scene: res://Sneces/Weapom/Firearms/AR/AK47/AK47.tscn
  • AK47 resource: res://Sneces/Weapom/Firearms/AR/AK47/AK47.tres

  • AK47 pickup: res://Sneces/Weapom/Firearms/AR/AK47/pickup_ak47.tscn

1. Bạn sẽ tạo những gì

Một weapon mới trong project này cần đủ 4 lớp dữ liệu: scene cầm trên tay, weapon resource, inventory item và pickup scene.

Thành phần File Vai trò
Weapon scene MyNewGun.tscn Scene được cầm trên tay, chạy cogito_weapon.gd
Weapon resource MyNewGun.tres Chứa fire mode, recoil, projectile, velocity
Wieldable item MyNewGun_Wieldable.tres Item trong inventory mà player equip
Pickup scene pickup_mynewgun.tscn Vật thể đặt trong map để nhặt
Điểm quan trọng Thiếu một trong bốn lớp này thì weapon thường sẽ rơi vào một trong các lỗi: nhặt không được, equip được nhưng không bắn, hoặc bắn được nhưng reload không ăn.

2. Mở AK47 để đối chiếu

A

Mở folder AK47 trong FileSystem

Left click: FileSystem dock Left click: Sneces → Weapom → Firearms → AR → AK47

Trong folder này bạn sẽ thấy đủ 4 file chính của một weapon hoàn chỉnh.

B

Những dữ liệu thật của AK47

  • AK47.tres: dùng AssaultRifle_Resource, fireRate = 600, Projectile, weaponVelocity = 715.
  • Ak-47_Wieldable.tres: charge_max = 30, charge_current = 30, ammo_item_name = "7.62x39mm".
  • pickup_ak47.tscn: PickupComponent.slot_data.inventory_item = Ak-47_Wieldable.tres.
  • AK47.tscn: gán weapon_data, sound_shoot, default_position, ads_position.

3. Dùng weapon setup tool

Đây là cách nhanh nhất để tạo bộ khung scene đúng chuẩn project.

1

Tạo scene tạm để chạy tool

Left click: Scene → New Scene Left click: Other Node Type: Node Left click: Create
2

Gắn script tool

Left click: root node Left drag: weapon_setup_tool.gd từ FileSystem vào root node
3

Điền 3 field trong Inspector

  • glb_model: kéo file .glb của súng vào.
  • weapon_name: ví dụ M4A1, không nên có khoảng trắng.
  • output_dir: ví dụ res://Sneces/Weapom/Firearms/AR/.
4

Bấm Generate

Left click: ⚙ Generate Weapon Scenes 
res://Sneces/Weapom/Firearms/AR/MyNewGun/MyNewGun.tscn
res://Sneces/Weapom/Firearms/AR/MyNewGun/MyNewGun_Drop.tscn
res://Sneces/Weapom/Firearms/AR/MyNewGun/pickup_mynewgun.tscn
Tool đã làm sẵn Tạo AnimationPlayer, AudioStreamPlayer3D, Bullet_Point, gắn cogito_weapon.gd, và set sẵn các animation cơ bản như equip, unequip, action_primary, reload.

4. Tạo Weapon_Resource

1

Tạo resource mới

Right click: folder weapon của bạn Left click: New Resource... Type: AssaultRifle_Resource nếu làm kiểu AK
2

Điền dữ liệu chính

  • weaponName: tên logic của súng.
  • recoilVertical, recoilHorizontal, recoilRecovery.
  • Type: chọn Projectile hoặc Hitscan.
  • bulletProjectileToLoad: scene viên đạn nếu dùng projectile.
  • weaponVelocity: tốc độ viên đạn.
  • fireRate: rounds per minute cho AR.

5. Tạo WieldableItemPD

1

Tạo item resource

Right click: folder weapon Left click: New Resource... Type: WieldableItemPD
2

Điền các field bắt buộc

  • wieldable_scene: kéo MyNewGun.tscn vào.
  • charge_max: magazine size, ví dụ 30.
  • charge_current: số đạn đang có sẵn khi spawn.
  • ammo_item_name: phải khớp chính xác với AmmoItemPD.name.
  • name, icon, drop_scene, item_size.
Bẫy dễ dính nhất ammo_item_name không đối chiếu theo tên file. Nó đối chiếu theo field name bên trong ammo resource. Ví dụ AK47 dùng name = "7.62x39mm".

6. Cấu hình weapon scene

1

Mở scene và chọn root node

Left double click: MyNewGun.tscn Left click: root node của weapon
2

Gắn dữ liệu chính trong Inspector

  • Kéo MyNewGun.tres vào field weapon_data.
  • Kéo audio vào sound_shoot và sound_reload nếu có.
  • Set default_position, ads_position, ads_fov.
  • Kéo mesh node vào wieldable_mesh.
3

Tên animation nên dùng

equip
unequip
action_primary
action_primary_ads
reload
reload_empty
reload_ads
reload_empty_ads
Ghi chú Nếu bạn chuẩn hoá toàn bộ weapon theo bộ tên này thì về sau đỡ phải set tay trong Inspector.

7. Cấu hình pickup scene

1

Mở pickup scene

Left double click: pickup_mynewgun.tscn
2

Gắn slot_data cho PickupComponent

Left click: node PickupComponent Left click: field slot_data Left click: mũi tên nhỏ bên phải Left click: New InventorySlotPD

Sau đó expand resource vừa tạo rồi kéo MyNewGun_Wieldable.tres vào field inventory_item.

3

Chỉnh collision nếu cần

Left click: CollisionShape3D Type / drag: chỉnh size cho đúng model

8. Tạo animation đúng tên

1

Mở AnimationPlayer

Left click: node AnimationPlayer Left click: tab Animation ở bottom dock nếu chưa hiện
2

Tạo animation mới

Left click: dropdown animation Left click: New Type: tên animation Left click: OK
3

Key transform

Chọn root weapon node hoặc mesh con trong Scene dock, rồi ở Inspector bấm biểu tượng key cạnh position, rotation, visible hoặc field nào bạn muốn animate.

4

Hiểu 4 loại reload

  • reload: reload hip fire, băng chưa rỗng.
  • reload_empty: reload hip fire khi băng rỗng.
  • reload_ads: reload khi đang ADS, băng chưa rỗng.
  • reload_empty_ads: reload khi ADS và băng rỗng.

9. Thả vào Town để test

1

Mở main scene

Left double click: res://Sneces/Town.tscn
2

Kéo pickup vào map

Left drag: pickup_mynewgun.tscn từ FileSystem vào 3D viewport Type / move: đặt gần vị trí spawn của player
3

Play và test đúng thứ tự

  • Nhặt pickup có vào inventory không.
  • Equip lên tay có đúng hướng và đúng vị trí không.
  • Bắn hip fire có trừ đạn không.
  • ADS có đổi FOV và dùng animation ADS không.
  • Reload thường có chạy reload không.
  • Bắn hết đạn rồi reload có chạy reload_empty hoặc reload_empty_ads không.
Dấu hiệu đã wire đúng Nhặt được, equip được, bắn được, ADS được, reload đúng animation và ammo lên lại đúng thời điểm.

10. Lỗi hay gặp

  • Dùng nhầm path kiểu Scenes / Weapon thay vì Sneces / Weapom.
  • ammo_item_name không khớp với AmmoItemPD.name.
  • Animation tồn tại nhưng đặt sai tên nên script không bao giờ gọi tới.
  • Quên gắn weapon_data vào root node của weapon scene.
  • Quên gắn wieldable_scene trong WieldableItemPD.
  • Quên gắn slot_data.inventory_item trong PickupComponent.
  • Dùng typo kiểu relaod_ads thay vì reload_ads.
File này được viết lại theo cấu trúc thực tế của project Cogito hiện tại và đã chỉnh CSS để các đoạn code/path dài tự xuống dòng.
