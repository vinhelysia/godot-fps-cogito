Documentation: Setup một weapon mới trong project này

Tài liệu này được viết dựa trên reference implementation AK47 trong project, không dựa trên giả định chung chung về Cogito. Mục tiêu là giúp bạn hiểu đúng data flow, scene ownership và runtime contract để thêm weapon mới mà không phải reverse-engineer lại toàn bộ hệ thống.

1. Tổng quan architecture

Trong repo này, weapon không chạy trực tiếp từ addons/cogito/Wieldables. Thay vào đó, project có một project-local adapter là res://Scripts/Weapons/cogito_weapon.gd, script này bridge giữa hệ inventory của Cogito và một hệ weapon data riêng của project.

Flow thật của weapon:
AmmoItemPD / WieldableItemPD trong inventory -> player gọi change_wieldable_to() -> scene weapon được instantiate vào Body/Neck/Head/Wieldables -> CogitoWeapon đọc Weapon_Resource -> khi fire thì dùng Bullet_Point, camera collision và inventory ammo để bắn / reload.
Weapon runtime script res://Scripts/Weapons/cogito_weapon.gd
Weapon base data res://Scripts/Weapons/Weapon_Resource.gd
Type-specific data res://Scripts/Weapons/Types/*.gd
Reference weapon folder res://Scene/Weapom/Firearms/AR/AK47/
Reference ammo folder res://Scene/Items/Bullets/
Player attachment point res://addons/cogito/PackedScenes/cogito_player.tscn

2. AK47 đang dùng những file nào

Nếu bạn muốn thêm một weapon mới nhanh nhất, hãy coi AK47 là template thực chiến. Toàn bộ slice của nó gồm các file sau:

  1. Scene/Weapom/Firearms/AR/AK47/AK47.tscn: scene weapon được cầm trên tay.
  2. Scene/Weapom/Firearms/AR/AK47/AK47.tres: weapon data resource kiểu AssaultRifle_Resource.
  3. Scene/Weapom/Firearms/AR/AK47/Ak-47_Wieldable.tres: inventory item kiểu WieldableItemPD.
  4. Scene/Weapom/Firearms/AR/AK47/AK47_Drop.tscn: mesh drop ngoài world.
  5. Scene/Weapom/Firearms/AR/AK47/pickup_ak47.tscn: pickup scene chứa interaction và slot data.
  6. Scene/Items/Bullets/7.62x39mm_Item.tres: ammo item kiểu AmmoItemPD.
  7. Scene/Items/Bullets/7.62x39mm_Item.tscn: pickup scene cho ammo.
  8. Scene/Weapom/BulletProjectil&shelle/7.62x39/7.62x39 projectile.tscn: projectile scene.
Khuyến nghị thực dụng:
Khi tạo weapon mới, duplicate weapon gần giống nhất rồi đổi mesh, animation, resource và pickup data. Làm vậy sẽ an toàn hơn nhiều so với việc dựng từ đầu một scene trắng.

3. Player đang kỳ vọng điều gì

Weapon scene của bạn chỉ hoạt động đúng nếu nó được instantiate vào đúng chỗ trong player template của Cogito. Scene cogito_player.tscn hiện đang expose các node path sau cho PlayerInteractionComponent:

  • interaction_raycast = ../Body/Neck/Head/Eyes/Camera/InteractionRaycast
  • carryable_position = ../Body/Neck/Head/Eyes/Camera/CarryablePosition
  • wieldable_container = ../Body/Neck/Head/Wieldables
  • CameraRecoil nằm ở Body/Neck/Head/CameraRecoil

CogitoWeapon đọc recoil node bằng path cứng Body/Neck/Head/CameraRecoil, nên nếu bạn đổi structure player scene thì weapon script sẽ không tự tìm lại được.

Caveat quan trọng:
Project có file res://Scripts/Player/player_interaction_component_delayed_reload.gd, nhưng scene cogito_player.tscn hiện vẫn instance res://addons/cogito/Components/PlayerInteractionComponent.tscn. Nghĩa là override reload local này hiện chưa được wire vào player mặc định.

4. Checklist setup weapon mới

Bước 1: Chọn fire model và type resource

Trước hết bạn phải quyết định weapon mới thuộc loại nào, vì CogitoWeapon sẽ đọc behavior từ subclass của Weapon_Resource.

Type script Dùng cho Field đang được runtime sử dụng
AssaultRifle_Resource.gd AR / auto rifle fireRate
Pistol_Resource.gd semi-auto pistol triggerResetTime
BoltAction_Resource.gd bolt-action rifle boltCycleAnimation
Shotgun_Resource.gd shotgun pelletCount, spreadAngle, adsSpreadAngle, isPump, pumpAnimation
LMG_Resource.gd LMG fireRate, heat / vent fields
MarksmanRifle_Resource.gd DMR / scoped rifle scopedFOV, scopeInTime
GrenadeLauncher_Resource.gd grenade launcher grenadeScene, launchAngle, launchVelocity, fuseDuration, blastRadius
Revolver_Resource.gd revolver Hiện tại mới khai báo data, chưa có logic đặc thù hoàn chỉnh trong CogitoWeapon

Bước 2: Tạo weapon data resource

Tạo một .tres mới dùng subclass phù hợp. Với AK47, file AK47.tres đang set: 

fireRate = 600
weaponName = "AK 47"
recoilVertical = 0.07
recoilHorizontal = 0.08
Type = 2
bulletProjectileToLoad = 7.62x39 projectile
weaponVelocity = 715

Ý nghĩa của phần base data:

  • weaponName: tên data resource, hiện không phải field quyết định HUD/inventory name.
  • recoilVertical và recoilHorizontal: hip-fire recoil mà weapon inject vào CameraRecoil.
  • Type: cách bắn, 1 = hitscan, 2 = projectile.
  • bulletProjectileToLoad: scene projectile nếu dùng projectile mode.
  • weaponVelocity: tốc độ projectile.
Đừng bật cả hai flag của Type.
Dù field được khai báo bằng @export_flags("Hitscan", "Projectile"), code hiện chỉ match giá trị 1 hoặc 2. Nếu bạn set thành 3, weapon sẽ không đi vào branch bắn nào cả.
recoilRecovery hiện chưa được dùng ở runtime.
Nó có trong Weapon_Resource, nhưng weapon_recoil.gd không đọc field này. Hiện recovery thật đang do returnSpeed của node CameraRecoil quyết định.

Bước 3: Tạo scene weapon được cầm trên tay

Scene root phải là Node3D có attach res://Scripts/Weapons/cogito_weapon.gd. Scene tối thiểu cần có:

  • AnimationPlayer
  • AudioStreamPlayer3D
  • Marker3D tên Bullet_Point và bật unique_name_in_owner
  • mesh weapon
  • optional: child node tên trigger nếu muốn trigger animation

Ở AK47, root scene export các field chính: 

weapon_data = AK47.tres
sound_shoot = shoot.wav
ads_fov = 40.0
default_position = (0.722, -0.3, -0.973)
ads_position = (0, -0.21, -0.8)
aim_recoil_values = (0.04, 0.045, 0)
wieldable_mesh = NodePath(".")

Với scene mới, bạn cần chỉnh ít nhất:

  1. weapon_data trỏ tới resource vừa tạo.
  2. sound_shoot và sound_reload.
  3. default_position và ads_position cho viewmodel alignment.
  4. aim_recoil_values nếu ADS recoil khác hip-fire.
  5. wieldable_mesh trỏ tới root mesh container cần hide/show khi equip.
Animation naming contract:
CogitoWeapon mặc định tìm các animation tên equip, unequip, action_primary, action_primary_ads, reload, reload_empty, reload_ads, reload_empty_ads. Nếu scene của bạn không có đủ những animation này, hãy đổi export string tương ứng trên root scene.

Bước 4: Tạo projectile scene nếu weapon dùng projectile

Nếu weapon của bạn bắn projectile, scene projectile nên derive từ res://addons/cogito/CogitoObjects/cogito_projectile.gd. AK47 đang dùng projectile 7.62x39 projectile.tscn và CogitoWeapon sẽ:

  1. instantiate projectile vào current scene,
  2. spawn ở Bullet_Point.global_position,
  3. set damage_amount,
  4. set linear velocity theo weaponVelocity,
  5. gán field Direction nếu projectile có field đó.

Nếu weapon là hitscan thì không cần projectile scene, chỉ cần set Type = 1.

Bước 5: Tạo inventory item cho weapon

Đây là bước rất dễ làm sai vì nhiều người nghĩ damage hoặc mag size nằm trong Weapon_Resource. Với project này, các giá trị magazine và combat stat mà player/HUD/reload dùng lại nằm trong WieldableItemPD.

Field Bắt buộc Ý nghĩa runtime
wieldable_scene Có Scene sẽ được instantiate khi player equip
charge_max Có Sức chứa magazine / charge max
charge_current Có Ammo đang có trong mag khi spawn item
ammo_item_name Có nếu reload Tên ammo item cần khớp 100% với AmmoItemPD.name
wieldable_range Nên có Tầm raycast từ camera, cũng là target point cho projectile aiming
wieldable_damage Nên có Damage emit vào target hoặc gán lên projectile/grenade
drop_scene Rất nên có Scene world object khi item bị drop
no_reload Optional Dùng cho melee hoặc weapon không xài ammo

AK47 sample đang set: 

wieldable_scene = AK47.tscn
charge_max = 30
charge_current = 30
ammo_item_name = "7.62x39mm"
name = "AK-47"
drop_scene = AK47 pickup/drop uid
item_size = (4, 2)
Điểm phải nhớ:
ammo_item_name và AmmoItemPD.name đang được match bằng string tuyệt đối. Sai 1 ký tự là reload sẽ không ăn.

Bước 6: Tạo ammo item

Ammo dùng class AmmoItemPD. Với AK47: 

name = "7.62x39mm"
is_stackable = true
stack_size = 70
drop_scene = 7.62x39mm_Item.tscn

Field quan trọng nhất ở ammo là reload_amount. Runtime reload trong CogitoWeapon đang tính lượng ammo nạp bằng công thức: 

ammo_loaded += ammo_item.reload_amount * slot.quantity

Nghĩa là:

  • Nếu ammo của bạn là từng viên đạn rời, để reload_amount = 1.
  • Nếu ammo pickup đại diện cho cả magazine hoặc battery pack, bạn có thể set lớn hơn 1.

Bước 7: Tạo drop scene

AK47_Drop.tscn chỉ là world mesh representation của khẩu súng. Nó không cần logic combat. Mục đích là để pickup scene có mesh hiển thị ngoài world mà không phải reuse nguyên viewmodel scene.

Bước 8: Tạo pickup scene cho weapon

Pickup scene của weapon nên follow đúng pattern của pickup_ak47.tscn:

  • Root là RigidBody3D có script CogitoObject
  • Instance drop mesh scene
  • ExtendedPickupInteraction để hiện hold prompt kiểu Wield
  • PickupComponent với slot_data.inventory_item trỏ tới WieldableItemPD
  • CarryableComponent nếu muốn cầm nắm object ngoài world
  • CollisionShape3D

Khi player hold interaction trên pickup này, ExtendedPickupInteraction sẽ:

  1. thử nhặt item vào inventory,
  2. nếu đang cầm weapon khác thì put away,
  3. sau đó gọi wieldable.use(player),
  4. weapon mới được equip ngay.

Bước 9: Tạo pickup scene cho ammo

Ammo pickup đơn giản hơn:

  • Root là RigidBody3D có script CogitoObject
  • PickupComponent với slot data trỏ tới AmmoItemPD
  • Collision + mesh đại diện cho ammo

Nếu player đang cầm weapon dùng đúng loại ammo, hệ pickup mặc định của Cogito sẽ update lại weapon HUD ngay sau khi nhặt.

Bước 10: Đặt weapon và ammo vào level

Cuối cùng, instance pickup scenes vào level. Scene Town.tscn đang instance trực tiếp:

  • pickup_ak47.tscn
  • 7.62x39mm_Item.tscn

Đây là cách đúng để test vòng đời hoàn chỉnh: nhặt súng -> equip -> bắn -> reload -> nhặt ammo -> bắn lại.

5. Runtime flow chi tiết

  1. Player dùng quickslot hoặc pickup interaction để dùng WieldableItemPD.
  2. WieldableItemPD.use() gọi change_wieldable_to(self) trên PlayerInteractionComponent.
  3. Player instantiate wieldable_scene vào Body/Neck/Head/Wieldables.
  4. Scene weapon được attach CogitoWeapon, nên weapon đọc weapon_data, setup recoil và chờ input.
  5. Khi fire:
    • charge_current bị trừ trên WieldableItemPD,
    • weapon chọn hitscan / projectile / shotgun / grenade branch,
    • damage lấy từ wieldable_damage.
  6. Khi reload:
    • weapon scan inventory theo ammo_item_name,
    • đợi reload animation finish,
    • sau đó mới trừ ammo item khỏi inventory và cộng lại vào charge_current.
Kết luận quan trọng:
Weapon_Resource không giữ state runtime như số đạn trong mag. State runtime thật nằm trong WieldableItemPD.

6. Common pitfalls

  • Sai tên ammo: ammo_item_name không khớp AmmoItemPD.name.
  • Quên Bullet_Point: scene weapon không có marker tên đúng hoặc không bật unique_name_in_owner.
  • Quên animation: root script đang gọi tên animation mặc định nhưng scene không có clip đó.
  • Set sai Type: dùng combined flag 3 thay vì chỉ 1 hoặc 2.
  • Đặt damage ở sai chỗ: damage thực tế lấy từ WieldableItemPD.wieldable_damage, không phải Weapon_Resource.
  • Đặt magazine size ở sai chỗ: mag size runtime là charge_max trên WieldableItemPD.
  • Đổi player structure: nếu player không còn Body/Neck/Head/CameraRecoil hoặc Body/Neck/Head/Wieldables, CogitoWeapon sẽ mất recoil hoặc mất attachment point.
  • Tin rằng mọi field type resource đều đã active: hiện có field được expose nhưng chưa có logic runtime đầy đủ, đặc biệt là revolver data.

7. Quy trình khuyến nghị để thêm weapon mới

  1. Duplicate folder của weapon gần giống nhất, ví dụ copy AK47 nếu làm rifle auto.
  2. Đổi mesh trong *.tscn weapon và *_Drop.tscn.
  3. Tạo hoặc chỉnh Weapon_Resource cho type đúng.
  4. Chỉnh WieldableItemPD cho mag size, damage, range, ammo name, icon.
  5. Tạo hoặc reuse AmmoItemPD phù hợp.
  6. Wire lại pickup scene của weapon và ammo.
  7. Đặt pickup vào level test.
  8. Test đầy đủ: pickup, equip, ADS, fire, empty mag, reload, ammo pickup, drop, equip lại.
Nếu mục tiêu là ship nhanh:
Đừng bắt đầu từ zero. Hãy duplicate AK47, đổi sang mesh mới, rồi chỉ chỉnh những phần sau: AK47.tres, AK47.tscn, Ak-47_Wieldable.tres, AK47_Drop.tscn, pickup_ak47.tscn, ammo resource/scene nếu cần.

8. Ghi chú implementation hiện tại

  • recoilRecovery mới là exposed data, chưa ảnh hưởng trực tiếp tới weapon_recoil.gd.
  • MarksmanRifle_Resource.useScopeOverlay và scopeOverlayTexture hiện chưa thấy được CogitoWeapon consume trực tiếp.
  • GrenadeLauncher_Resource.explosionScene hiện mới là data field, chưa được spawn trực tiếp trong CogitoWeapon.
  • Revolver_Resource có field data nhưng chưa có custom reload / chamber logic hoàn chỉnh ở runtime weapon script.
  • Reload thật sự trừ ammo inventory ở cuối animation thông qua _on_anim_finished().

Nếu bạn muốn, bước tiếp theo hợp lý là viết thêm một tài liệu companion dạng “clone AK47 thành weapon mới trong 15 phút” hoặc một “weapon setup checklist” ngắn gọn chỉ gồm các thao tác editor.
